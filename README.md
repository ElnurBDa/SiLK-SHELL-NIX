# SiLK-SHELL-NIX
shell.nix file to use SiLK (Network Analysis Tool).
Used for Nix environments.

## Setup

1. Download the archive from https://tools.netsa.cert.org/silk/download.html
2. put the `shell.nix` file into the codebase
3. `nix-shell` in this directory
4. Use SiLK related tools in this temp terminal
